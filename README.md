# Google-Arama-Kisayollar-
Google arama parametleri

# Google Arama Parametreleri 

1. `"kelime kelime"` → Birebir ifade  
   `"bilgi güvenliği"`

2. `-kelime` → Hariç tut  
   `teknoloji -google`

3. `site:siteadi.com` → Sadece belirtilen site  
   `site:wikipedia.org tarih`

4. `filetype:uzanti` → Dosya türü  
   `rapor filetype:pdf`

5. `intitle:kelime` → Başlıkta geçen  
   `intitle:rehber`

6. `allintitle:kelime1 kelime2` → Başlıkta tüm kelimeler  
   `allintitle:google arama`

7. `inurl:kelime` → URL içinde  
   `inurl:blog`

8. `allinurl:kelime1 kelime2` → URL’de tüm kelimeler  
   `allinurl:egitim dokuman`

9. `OR` → Alternatif  
   `kitap OR dergi`

10. `*` → Joker  
    `en iyi * rehberi`

11. `..` → Sayı aralığı  
    `telefon 5000..10000`

12. `related:siteadi.com` → Benzer siteler  
    `related:bbc.com`

13. `cache:siteadi.com` → Google önbelleği  
    `cache:example.com`

14. `define:kelime` → Tanım  
    `define:algoritma`

15. `before:yil` → Belirtilen yıldan önce  
    `yapay zeka before:2020`

16. `after:yil` → Belirtilen yıldan sonra  
    `yapay zeka after:2023`

17. `source:kaynak` → Haber kaynağı  
    `ekonomi source:bbc`

18. `info:siteadi.com` → Site bilgisi  
    `info:wikipedia.org`

19. `()` → Gruplama  
    `(tarih OR arkeoloji) kitap`

20. `+kelime` → Zorunlu kelime  
    `+rehber +pdf`
